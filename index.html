    How it works

    The converter uses your template — a blank SageMath HTML notebook — as the host environment. The template is loaded into a hidden iframe, which means the version of nbrunner used is whichever the template references. To upgrade the conversion engine, just re-export and upload a fresh template.

    For each .ipynb you supply, the page:

    1. Loads a fresh copy of the template into an isolated iframe.
    2. Calls the template's own importFromIPYNB() to load your notebook.
    3. Waits for cells to render and KaTeX/MathJax to settle.
    4. Calls the template's own saveHtml(), intercepts the produced blob, and stores it.

    A single notebook is downloaded directly as .html. Multiple notebooks are bundled into one .zip using fflate, so you only get one download.

    About the timing settings

    The two timers below control how long the converter waits between operations inside the iframe. They exist because rendering happens asynchronously (KaTeX, image loading, the nbrunner reprocess pass) and the page can't know in advance when it's truly done. Defaults work for typical notebooks — increase them if you see incomplete output, decrease them to speed up batches of small files.

    SettingWhat it controlsWhen to change it
    Settle time How long to wait after importFromIPYNB() before calling saveHtml(). Gives cells, math, and images time to finish rendering. Increase (e.g. 4000–6000 ms) for long notebooks with lots of LaTeX or large outputs.
    Decrease (e.g. 1500 ms) for short notebooks if you want batches to finish faster.
    Per-file delay Pause between consecutive conversions, after one is finished and before the next iframe is created. Usually fine at the default. Increase if your browser seems sluggish during big batches; set to 0 for maximum speed.
